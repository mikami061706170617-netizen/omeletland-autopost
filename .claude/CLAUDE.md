# 作業の分担（モデルの使い分け）

- **メイン（Sonnet）**: 実装・コード編集・テスト実行を自分で行う。
- **調査は `researcher` サブエージェント（Haiku）に任せる**: ファイル探し、コード構造の解析、
  ドキュメント調査。同時に動かすのは **最大 3 つまで**。返ってきた要約だけを使い、
  ファイル全文をメインの会話に読み込まない。
- **アドバイザー（Opus）に相談するのは次のときだけ**:
  1. 複数ファイルにまたがる設計・計画を確定する前
  2. 同じテスト失敗・コンパイルエラーが 2 回起きたとき
  3. 作業完了と報告する前の、最終 diff の確認
  4. 重要なコミットの前
- 日常的な作業（1 ファイルの小さな修正、調べもの、定型の編集）ではアドバイザーを呼ばない。
