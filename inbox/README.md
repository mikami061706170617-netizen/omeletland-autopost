# inbox — 撮ったオムライス動画をここに置く

1. 写真アプリで動画を選び、Finder のこのフォルダ（inbox）へ**そのままドラッグ**
   （ブラウザではなく Finder へ。ブラウザにドラッグすると表紙の画像だけになる）
2. `アップロード.command` をダブルクリック
   - 90MB を超える動画は、Mac 標準の avconvert で自動的に小さくしてから送る
   - 小さくできなかった動画は `inbox_保留/` に移して送らない
3. 数分で Actions が編集 → `reels/` に完成版ができ、`reels.json` に登録される
   - 長い動画（数分〜）は自動でタイムラプス風に早送りして 60 秒以内に収める
4. 次の 20:00 に、リール＋ストーリーズ＋Facebook に自動で出る
   （元の動画は編集後に inbox から自動で消える）

## パカーンの瞬間を指定したいとき（おすすめ）
ファイル名に `_t秒数` を入れる。例: `omurice_t14.5.mov` → 14.5秒目でスロー＋効果音。
指定しないと動画の 65% の位置になる。

料理名や価格も入れたいときは、同じ名前の `.json` を横に置く:

```json
{"reveal": 14.5, "dish": "No.01 Classic Omurice", "price": 25, "start": 2, "end": 40}
```

- 実写のみ。トビリシの店で撮ったものだけ。
