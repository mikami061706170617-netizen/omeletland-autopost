# inbox — 撮ったオムライス動画をここに置く

## いちばんかんたん（おすすめ・おとひまと同じ）
1. 写真アプリで撮った動画を、アルバム「**オムライス送る**」に入れる（初回は自動でできます）
2. `アップロード.command` をダブルクリック
   - 1本ずつ写真アプリから取り出して GitHub の「素材置き場」に送る。**大きな動画もそのまま**（1本2GBまで）
   - 送った動画は Mac から消す（写真アプリの元の動画はそのまま）。同じ動画は二度送らない
3. 数分で Actions がコマ見本を作る → 毎朝 10:00 ごろ Claude がパカーンの瞬間を選んで、
   リール（Instagram・Facebook）と YouTube ショートに編集して、投稿の順番に入れる
4. 使い終わった動画は素材置き場から自動で消える（リポジトリは Public なので残さない）

このフォルダ（inbox）に動画ファイルを直接入れて `アップロード.command` を押しても、同じように素材置き場へ送られます。

## 手で指定したいとき（ふだんは不要）
ふだんは Claude がコマ見本を見て選ぶので、何もしなくてOK。
（Actions の make_reel.yml で直接リールにする古いやり方では、ファイル名の `_t秒数` と同名 `.json` を使います。
例: `omurice_t14.5.mov` → 14.5秒目でスロー＋効果音。指定しないと動画の 65% の位置）

```json
{"reveal": 14.5, "dish": "No.01 Classic Omurice", "price": 25, "start": 2, "end": 40}
```

- 実写のみ。トビリシの店で撮ったものだけ。
